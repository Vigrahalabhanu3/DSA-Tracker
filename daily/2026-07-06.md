- **Longest Substring Without Repeating Characters** 🟡 (Medium) — LeetCode [Strings]

**Topics**: DynamicProgramming, Backtracking, Strings, Heap
**Hours**: 2.0h

**Review Notes**:
Strong afternoon session — carried the morning DP momentum straight into mediums, then branched into backtracking and finished with a confidence-boosting hard.

House Robber: Classic 1D DP — rob[i] = max(rob[i-1], rob[i-2] + nums[i]). The key insight is this isn't about alternating houses; each house you either skip or take + skip the adjacent. O(n) time, O(1) space with two variables.

Coin Change: Unbounded knapsack variant — dp[amount] = min coins needed. Initialize dp[0]=0, rest=INF. For each coin, dp[i] = min(dp[i], 1 + dp[i-coin]). O(amount × coins) time. Watch for the unreachable case (return -1 when dp[amount] = INF).

Subsets: The prototypical backtracking problem. For each element, two choices: include or exclude. Build the subset incrementally via recursion — push, recurse, pop (backtrack). Time O(2ⁿ), space O(n) for recursion depth. Can also do iterative with bitmask 0 to 2ⁿ-1.

Combination Sum: Backtracking with a twist — unlimited uses per element. Key difference from Subsets: we track remaining target, not just include/exclude. Sort candidates for early pruning. Recursion: for i in range(start, n), if candidates[i] > target: break; push, recurse(i, target - c[i]), pop. The `start` index prevents duplicate combinations.

Longest Substring Without Repeating Characters: Sliding window classic. Maintain a set/array of seen chars, expand right, shrink left when duplicate found. Track max window size. O(n) with two pointers — each char added and removed at most once.

Merge k Sorted Lists: First hard! Two approaches: (1) Min-heap — push all heads, pop smallest, push next from that list. O(N log k). (2) Divide & conquer merge — pair up lists recursively like merge sort. Heap approach is cleaner. Important: use a dummy head, track current tail, handle nulls carefully.

**Key Takeaways**:
- DP: Identify the recurrence FIRST — House Robber's skip/take decision, Coin Change's min-over-coins
- Backtracking: Template = choose → explore → unchoose. Subsets (include/exclude) vs Combination Sum (build to target with repeats)
- Sliding window: Two-pointer invariant — window always contains unique chars. When violated, shrink.
- Heap for k-way merge: Always compare k candidates, take the smallest, advance exactly one pointer
- First hard done! Merge k Sorted Lists demystified — it's just k-way merge with a priority queue
